## 사용자 실행 필요 (Claude 도구 한계)

Claude Code는 (1) 비밀번호를 직접 입력할 수 없고, (2) 브라우저의 네이티브 파일 선택창(`<input type=file>`)을 조작할 수 없습니다. 아래는 실제 사진이 있어야 의미 있게 검증되는 케이스라 직접 실행해주셔야 합니다.

| DETAIL-3 | 수량 확인/수정 후 저장 → 라벨 장수와 비교해 일치/불일치가 맞게 뜨는지 |

## 그 외 관찰 사항 (버그는 아님, 참고용)

1. **검수 이력의 표시 이름이 이메일 앞부분**(`bsy7616`)으로 나옵니다. 동작은 맞지만, 가족 여러 명이 쓰면 "누가" 했는지 한눈에 안 보일 수 있습니다 — 필요하면 나중에 표시 이름을 직접 설정하는 기능을 추가할 수 있습니다.
2. **테스트 중 만들어진 빈 배송이 다수 쌓여 있습니다** (대부분 "남부터미널", 라벨 0장). 실제 데이터가 아니라 이전 테스트 흔적으로 보입니다 — 정리가 필요하면 말씀해주세요. 이번 QA용으로 제가 만든 것들은 이미 삭제했습니다.
3. Vercel Hobby 플랜의 "Blocked" 배포는 **앞으로도 같은 계정 조합으로 푸시할 때마다 재발**합니다. Pro로 업그레이드하지 않는 한 계속 public 상태를 유지해야 자동배포가 됩니다.
