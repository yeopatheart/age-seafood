# age-seafood 테스트 계획 (2026-09-27)

자동 테스트 프레임워크가 없는 프로젝트라(AGENTS.md) 이 문서가 테스트의 기준점이다. 시나리오·케이스를 여기 적고, 실행 결과는 `2026-09-27-test-results.md`에 남긴다.

## 범위

- 인증, 배송 목록/생성/상세, 라벨 사진 일괄 업로드(AI 터미널 자동분류), 버스 송장 AI 수량 제안, 스와이프 검수, 기록 조회, 설정(글자 크기), PWA, 성능

## 실행 제약 (미리 밝혀둠)

- Claude Code는 비밀번호를 직접 입력할 수 없다 — 로그인은 항상 사용자가 직접 한다
- Claude Code의 브라우저 도구는 `<input type=file>`의 네이티브 OS 파일 선택창을 조작할 수 없다 — **실제 사진을 올리는 케이스는 전부 사용자가 직접 실행해야 한다**
- 따라서 이 문서의 케이스는 "Claude가 직접 검증 가능" / "사용자가 직접 해야 함" 두 갈래로 나눈다
