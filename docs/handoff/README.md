# 인수인계

`@spec-writer` 가 소유한다. 읽는 대상은 사람이 아니라 **Cursor와 v0.dev** 다.

- `<기능>-cursor.md` — Cursor Pro가 구현할 스펙 (데이터 모델, API 계약, 완료 판정)
- `<화면>-v0.md` — v0.dev에 그대로 붙여넣을 프롬프트

## 규칙
- 미결 사항이 하나라도 있으면 스펙을 쓰지 않는다. 무엇이 안 정해졌는지 되돌려 보낸다.
- 프로젝트 `AGENTS.md`에 이미 있는 규칙은 다시 쓰지 않는다. Cursor가 그 파일을 읽는다.
- 완료 판정은 실행해서 확인 가능한 문장으로 쓴다.
